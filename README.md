## 🌱 Growth Mindset

Starting a degree in Cyber Security is both exciting and challenging. Security is an ever-evolving field — new vulnerabilities are discovered every day, and defenders must always stay one step ahead. I believe in:

- **Continuous learning** — technology changes; curiosity shouldn't
- **Hands-on practice** — reading alone isn't enough; building and breaking things is how you truly learn
- **Community** — sharing knowledge makes everyone more secure
- **Ethics** — responsible disclosure and legal practice are non-negotiable in this field
